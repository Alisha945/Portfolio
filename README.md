A modern, responsive personal portfolio website developed to showcase my skills, projects, education, certifications, and professional profile as a fresher looking for opportunities in the software development and IT industry.

🚀 About the Project

This portfolio website serves as my personal online profile where recruiters and developers can learn more about me, my technical skills, projects, and experience.

The website has been designed with a clean and professional interface and is optimized for both desktop and mobile devices.

✨ Features
🏠 Home – Introduction and professional overview
👩‍💻 About Me – Educational background and personal profile
🛠️ Skills – Technical skills and technologies
💼 Services – Development and technical services
📂 Projects – Showcase of my academic and personal projects
📜 Certifications – Display of professional certifications
📞 Contact – Contact section for connecting with me
📱 Responsive Design – Works across desktop, tablet, and mobile screens
🎨 Modern UI – Clean and user-friendly interface
📄 Resume/CV – Easy access to my professional resume
