Cloud Weaving Model is a cloud networking and infrastructure design project developed using Amazon Web Services (AWS). The project focuses on creating a secure, scalable, and well-structured cloud architecture by integrating various AWS networking components such as VPCs, subnets, route tables, internet gateways, and EC2 instances. The main objective of this project was to understand and implement cloud networking concepts practically while designing a reliable infrastructure for secure communication and resource management in the cloud environment.
