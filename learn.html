Learnify -Education Hub is a desktop-based educational management system developed using Python, Tkinter, and SQLite. The project was designed to simplify and digitalize the management of students, courses, results, and educational records through an interactive graphical user interface. The application helps educational institutions efficiently manage academic information while reducing manual paperwork and improving data organization.This project improved my programming, database handling, and GUI development skills while giving me practical experience in building real-world desktop applications using Python technologies.
